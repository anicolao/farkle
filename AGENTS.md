# Farkle

Use Bun and `codex/` branches with pull requests. GPL-3.0-only.
Keep the pure versioned intent log canonical; no derived outcomes in Firestore.

local development and tests. Never connect tests to the production project.

invent seeded outcomes for physical rolls. Keep native 3D dice tapping and visible
keyboard equivalents. Verify types, engine tests, Firestore rules, browser flows
and build. Every same-repository PR gets an independent GitHub Pages preview.
